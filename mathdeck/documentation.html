LaTeX Math and Equations for Confluence

Last updated: 4 October 2026

Adding a formula

  1. In the Confluence editor, type /latex and pick LaTeX Math.
  2. A configuration panel opens with a live preview. Pick a starter template or paste your own LaTeX on the left; the typeset result appears on the right as you type.
  3. Save. The panel closes and the typeset formula appears in the page.

To change a formula later, edit the macro — the panel reopens with your existing source in it. The starter templates are only pre-filled when you insert a new macro, so editing can never overwrite what you already wrote.

Writing LaTeX

The macro understands the usual LaTeX maths delimiters:

DelimitersResult
$…$ · \(…\)Inline — sits in the line of text
$$…$$ · \[…\]Display — on a line of its own, centred

A display formula:

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

Everything in one macro is typeset together, so text and maths can share it. This whole block is one macro, and only the part in $…$ is typeset:

Euler's identity $e^{i\pi} + 1 = 0$ follows from the exponential series.

You do not have to add delimiters at all. If the source contains no delimiters it is treated as a single formula — a single line is typeset inline, several lines (or a \begin{…} environment) are typeset as display.

Pasting from somewhere else

Copying LaTeX out of a PDF, a Word document, a chat message or a Markdown file often brings invisible characters with it. The macro cleans up the common ones before typesetting: Windows line endings, non-breaking spaces, zero-width characters, and a surrounding ```latex code fence. If your formula typesets after pasting but not before, that is usually why.

Errors

When the source cannot be typeset, the macro shows the line number, the offending line itself and a marker under the position where typesetting stopped, plus the library's original message if you want it. A single bad formula does not stop the rest of the macro — anything that can be typeset still is. Two messages mean something specific:

  • Needs a line of its own — an \begin{align} (or similar) environment was used inside $…$. Wrap it in $$…$$ instead.
  • Unknown command — the command does not exist in the bundled library, usually a typo, or it comes from a LaTeX package that is not bundled.

Limits

  • Up to 20,000 characters and 500 lines per macro.
  • Formulas are typeset, not exported — there is no PNG or SVG download in this version.
  • Commands that produce links or pull in external content are deliberately disabled (\href, \url, \includegraphics, \htmlClass); they are shown as text instead.
  • The macro typesets whatever the bundled library supports. LaTeX features released after this app version will not be understood until the app is updated.
