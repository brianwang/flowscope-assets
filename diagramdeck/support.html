Common questions

The macro says it could not parse my diagram

The message names the line and column and shows the line itself. Most parse errors come from the first line: Mermaid needs a diagram type there, such as flowchart TD, sequenceDiagram, stateDiagram-v2, classDiagram, erDiagram or gantt.

Can I get the diagram out as an image?

Not in this version. The diagram is drawn on the page each time it is viewed, so what you see is always the current text — there is no stale exported file to keep in sync. If you need an image file, the diagram can be screenshotted or printed from the page.

Does this macro send my diagram text anywhere?

No. See the Security and Privacy pages.

Which diagram types are supported?

Whatever the bundled version of Mermaid supports — flowcharts, sequence, class, state, ER, Gantt, pie, journey, git graph, mindmap, timeline, quadrant, XY chart, block, requirement, C4, sankey, architecture, kanban, packet, radar and treemap. See Documentation.
