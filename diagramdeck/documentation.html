Mermaid Diagram for Confluence

Last updated: 2 October 2026

Adding a diagram

  1. In the Confluence editor, type /mermaid and pick Mermaid Diagram.
  2. A configuration panel opens. Pick one of the starter templates or paste your own Mermaid text.
  3. The preview updates as you type, and any parse error is shown against the line it is on.
  4. Save. The macro closes and the rendered diagram appears in the page.

To change a diagram later, edit the macro — the panel reopens with your existing text in it.

Writing Mermaid

Mermaid is a plain-text diagramming language. Every diagram starts with its type on the first line. A flowchart, for example:

flowchart TD
    A[Reported] --> B{Triage}
    B -->|urgent| C[Fix now]
    B -->|normal| D[Schedule]
    C --> E[Released]
    D --> E

The first line sets the direction: TD top-down, LR left-right, BT and RL for the reverse. Node shapes come from the brackets — [ ] rectangle, ( ) rounded, { } diamond, (( )) circle. Labels on arrows go between the vertical bars, as above.

Pasting from somewhere else

Copying Mermaid out of a README, a chat message or a ticket often brings invisible characters with it. The macro cleans up the common ones before rendering: Windows line endings, non-breaking spaces, zero-width characters, and a surrounding ```mermaid code fence. If your diagram renders after pasting but not before, that is usually why.

Errors

When the text cannot be parsed, the macro shows the line number, the offending line itself and a marker under the position where parsing stopped, plus the parser's original message if you want it. The most common cause by far is a missing or misspelled diagram type on the first line.

Limits

  • Up to 20,000 characters and 500 lines per diagram.
  • Diagrams are drawn, not exported — there is no PNG or SVG download in this version.
  • The macro renders whatever the bundled Mermaid version supports. New Mermaid syntax released after this app version will not be understood until the app is updated.
