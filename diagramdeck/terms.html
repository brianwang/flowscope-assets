1. What the app is

The app is a Confluence macro. It takes the Mermaid text saved in the macro's configuration and renders it as an SVG diagram directly on the page. It has no server, no database and no storage of its own: it requests no OAuth scopes, and it makes no outbound network requests. The diagramming library is bundled inside the app rather than fetched from a CDN.

The only thing the app persists is the macro configuration itself — the Mermaid text — which Confluence stores as part of the page, under Confluence's own storage, permissions and retention. The app does not read Jira issues, other Confluence pages, comments, attachments, user profiles or space permissions, and it has not been granted the ability to do so.
