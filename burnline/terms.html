1. What the app is

The app is a read-only gadget. It reads Jira issues through the Jira REST API, using the read:jira-work scope and nothing else, and draws a burnup / burndown chart on a dashboard: how much work was in scope on each day, how much was delivered, how much remained, and the weekly throughput behind those lines. It does not create, edit or transition issues, it does not write to your Jira data, and it does not run scheduled jobs.

Every read is made as the user viewing the gadget, so the app can only ever see the issues that viewer is already allowed to see. It never uses an administrator identity. Installing the app grants it no access beyond the scope above.
