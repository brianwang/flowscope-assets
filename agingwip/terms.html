1. What the app is

The app is a Jira dashboard gadget. For issues matched by a JQL filter that a Jira administrator configures on the gadget, it shows how long each in-flight item has been sitting in its current status, with 50/70/85/95th percentile lines. It reads, per issue, the issue key, the status transition history and the creation date, through the official Jira REST API using the read:jira-work scope and nothing else. All requests are made as the user who is viewing the gadget, so it can only ever show issues that the person looking at the dashboard is already allowed to see.

The app writes one short-lived cache record per configuration per user — keyed by the Atlassian account ID of the viewer, holding the computed result only, kept for 1 hour — into Atlassian's own Forge app storage. The app has no server, no database and no storage of its own, and it makes no outbound network requests to any host other than Atlassian's Jira API.
