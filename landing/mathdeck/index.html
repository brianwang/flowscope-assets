LaTeX Math and Equations for Confluence

LaTeX Math and Equations for Confluence

Paste LaTeX into the macro and the formula is typeset on the page. Inline formulas sit in the line of text; display formulas get a line of their own. The source stays as text in the macro, so a formula is edited, reviewed and version-controlled like the rest of the page rather than like an attached picture.

What it does

  • Inline and display formulas in one macro$...$, \(...\), $$...$$ and \[...\] are all understood, and one macro can hold text and maths together.
  • Live preview while you typeWith a starter template for the common shapes: display formula, inline in a sentence, aligned equations, matrix, piecewise function.
  • Formats come from the LaTeX itselfFractions, integrals with limits, roots, matrices with stretchy parentheses, aligned multi-line blocks.
  • Light and dark pages both workFormulas take the page's text colour.
  • The invisible characters a paste brings along are strippedWindows line endings, non-breaking spaces, zero-width characters and a surrounding latex code fence, before typesetting.
  • No server of oursNo OAuth scopes, no outbound network requests, no API tokens - the app declares no backend function and keeps no storage.

When the source is wrong, it tells you where

  • The line number, the line itself, and a markerA marker under the position where typesetting stopped, plus the typesetting engine's original message if you want it.
  • Two cases get named in plain wordsAn align-style environment used inline ("needs a line of its own"), and a command that does not exist ("unknown command").
  • Limits, stated up frontUp to 20,000 characters and 500 lines per formula. Formulas are typeset, not exported: there is no PNG or SVG download in this version.
  • Commands that would pull in external content are deliberately disabled\href, \url, \includegraphics and \htmlClass are shown as text instead.
  • English and Simplified Chinese
