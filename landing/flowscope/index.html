Cycle Time Scatter Chart for Jira Dashboard

Pick a filter and the two statuses that mean started and done. Every completed work item becomes a point: completion date against cycle time.

View on the Atlassian Marketplace

A Forge app for Jira Cloud. Free to try on a site you administer.

What it does

  • A scatter, not an averageAverages hide the tail, and the tail is what misses deadlines.
  • 50 / 70 / 85 / 95th percentile linesLabelled in days, so you can see where your predictable zone ends.
  • A summary lineSample size, median and 85th percentile.
  • Statuses picked from a list, stored by IDThe gadget keeps working whatever language your Jira is displayed in - you never type a status name.
  • Read-onlyReads issues through the Jira REST API with a read-only scope. No data goes to any external service.

How it counts

  • Calendar days, not working days
  • Reopened issues use the LAST completionIf an issue re-entered the start status, the last entry is used.
  • Never silently zeroItems whose start cannot be established are excluded, and the excluded count is shown.
  • Sample-size honestyPercentile lines are omitted below a minimum sample, with the reason shown on the chart.
  • English and Simplified Chinese
