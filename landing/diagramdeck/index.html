Mermaid Diagram for Confluence

Write or paste Mermaid text into the macro and the diagram renders on the page. Your diagram lives as text in the page, so it diffs, reviews and version-controls like everything else in the page.

View on the Atlassian Marketplace

A Forge app for Jira Cloud. Free to try on a site you administer.

What it does

  • Renders Mermaid text as an SVG diagram inline in the page
  • Live preview while you typeWith a starter template for each common diagram type.
  • The diagram types Mermaid supportsFlowcharts, sequence, class, state, ER, Gantt and more.
  • Light and dark themes follow the page
  • When the text is wrong, it says whereIt shows the line number, the line itself and a marker under the position where parsing stopped, plus the parser's original message.
  • It strips the invisible characters that come with a pasteWindows line endings, non-breaking spaces, zero-width characters and a surrounding code fence, before rendering.
  • No OAuth scopes, no outbound network, no API tokens, no server of oursThe diagramming library is bundled rather than loaded from a CDN; the app declares no backend function and keeps no storage.

Limits, stated up front

  • Drawn on the page, not exportedThere is no PNG or SVG download in this version.
  • Up to 20,000 characters and 500 lines per diagram
  • New Mermaid syntax released after this app versionIs not understood until the app is updated.
  • English and Simplified Chinese
