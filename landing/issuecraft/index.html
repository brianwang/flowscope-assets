Issue Templates for Jira

Pick a project, pick a template, adjust what you need, and create the issue. The issue type, summary, description, labels and components come from the template, so everyone on the team files work the same way - instead of everyone inventing their own idea of what a bug report looks like.

A Forge app for Jira Cloud.

What it does

  • Ten built-in templatesBug report, feature request, user story with acceptance criteria, technical spike, production incident, test case, design doc / RFC, epic brief, decision record, handover.
  • Templates the project cannot create are hiddenWith a count and the reason. Sub-task types are left out: a sub-task needs a parent, and choosing one is a decision this app does not make for you.
  • Edit anything before creatingIssue type, summary, description, labels, priority, components.
  • Descriptions are plain textHeadings, bullets, checkboxes, numbered lists, rules and fenced code blocks, converted to Jira's document format on the way in. {{date}} and {{project}} are filled in at creation time.
  • Nothing is created until you press createOne press creates one issue. There is no bulk mode, no scheduled action and no retry loop.
  • Reads the Jira REST API as youNo app storage of its own, and no data sent to any external service: no analytics, no third-party integrations, no egress.

Nothing is changed silently

  • Every adjustment is listed on the confirmationA summary with a line break or tab put on one line, a summary longer than 255 characters cut to fit, a label containing a space given dashes, duplicate labels dropped, a component the project does not have dropped, a priority the project does not have left at the project default.
  • It never guesses a substituteIf it cannot find the component or the priority you asked for, it drops it and tells you which one.
  • If the creation fails, nothing is left behindThere is no half-made issue.
  • Issue types are matched on their internal name firstSo a Bug issue type displayed as 缺陷 is still found on a site whose Jira is shown in another language. The app UI is available in English and Chinese (Simplified).
