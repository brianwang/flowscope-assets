Please do not send API tokens or any other credentials.

Common questions

  • The gadget says "no work items were completed". The app always adds statusCategory = Done and a resolution-date window to your filter. If your projects do not resolve work items — or nothing was completed in that window — the result is genuinely empty. Try a wider window.
  • Coverage looks lower than expected. Coverage counts work items, not hours. An item counts as logged as soon as anyone has logged any time against it. If only some of your projects use Jira's time tracking, include only those projects in the filter — otherwise the projects that never log time will pull the number down.
  • The number changes when I refresh. Results are cached for up to 1 hour.
