1. What the app is

The app is a read-only dashboard gadget. It reads Jira work items and their worklogs through the Jira REST API, using the read:jira-work scope and nothing else, and reports how many of the items completed in a chosen period have no time logged against them, broken down by assignee. It does not create, edit or transition work items, it does not write worklogs, it does not comment, and it does not run scheduled jobs.

Every read is made as the user viewing the gadget, so the app can only ever see work items that viewer is already allowed to see. It never uses an administrator identity. Installing the app grants it no access beyond the scope above.
