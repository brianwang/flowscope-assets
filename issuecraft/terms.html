1. What the app is

The app is a Jira full-page app under the Apps menu. It turns filing work into picking a template: you choose one of the built-in team templates, adjust the fields you need, and it creates exactly the one issue you reviewed and pressed create for, in the project you selected. It reads the projects you are allowed to file in and the issue types, components and priorities of the selected project via the official Jira REST API, using the read:jira-work and write:jira-work scopes. All requests are made as the user who is using the app — it can only ever act within what that person is already allowed to do, and it never uses an administrator identity.

The app stores nothing of its own: no database, no cache, no per-user record. The only thing it writes outside your Jira issues is a single runtime log line on a successful creation (the issue key, the project key, the creating user's Atlassian account ID, and which template was used) which is hosted and retained by Atlassian. It has no server of its own and makes no outbound network requests to any host other than Atlassian's Jira API.
